# Sous Chef Recipe Manager
Sous Chef is a lightweight and self-hostable web recipe management software. Following clean architecture principles it makes use of of separate UI and API for flexibility and organization. Built on .NET 8 using Blazor, Minimal APIs, and Fast Endpoints.

## Contributors

## Try it out
Simply download the source code and use the included docker compose file with your preferred docker engine setup.
